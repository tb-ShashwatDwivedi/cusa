# CUSA Event Schema

**Canonical internal event model.** Collectors produce this structure. The Wazuh compatibility layer translates it to manager-facing wire format.

Implementation: `agent/src/pipeline/event.schema.js`

---

## Design Goals

1. **Collector-agnostic** — no Wazuh queue types, encryption, or NDJSON knowledge
2. **Validatable** — JSON Schema enforced at pipeline boundary via Ajv
3. **Extensible** — `metadata` for CUSA-internal fields never sent to Wazuh wire
4. **ECS-aligned where practical** — aids future SIEM correlation without mandating ECS on wire

---

## Canonical Event Structure

```js
{
  eventId,        // UUID v4, generated by pipeline
  agentId,        // CUSA agent identity (post-enrollment)
  timestamp,      // Event occurrence time (ISO 8601)
  collectedAt,    // Collection time (ISO 8601)

  source: {
    platform,     // "windows" | "linux"
    collector,    // e.g. "event-channel", "sysmon", "journald", "fim"
    channel,      // e.g. "Security", "Microsoft-Windows-Sysmon/Operational"
    path          // file path for file-based collectors
  },

  host: {
    hostname,
    os,           // "Windows" | "Linux" | ...
    osVersion,
    architecture,
    ips,          // string[]
    macs          // string[]
  },

  event: {
    category,     // e.g. "authentication", "process", "file", "configuration"
    type,         // e.g. "start", "end", "info", "denied"
    action,       // e.g. "logon-failed", "process-created"
    severity      // 0-10 or "low"|"medium"|"high"|"critical"
  },

  user,           // optional — see User object
  process,        // optional — see Process object
  network,        // optional — see Network object
  file,           // optional — see File object

  raw,            // original log/event string or object
  metadata        // CUSA-internal only, never on Wazuh wire
}
```

## Field Definitions

### Required Fields

| Field | Type | Description |
|-------|------|-------------|
| `eventId` | `string` (uuid) | Unique event identifier |
| `timestamp` | `string` (date-time) | When the event occurred on the endpoint |
| `collectedAt` | `string` (date-time) | When CUSA collected the event |
| `source.platform` | `string` | `windows` or `linux` |
| `source.collector` | `string` | Collector module name |
| `event.category` | `string` | Event category |
| `raw` | `string` \| `object` | Original event data |

### Optional Fields

| Field | Type | Description |
|-------|------|-------------|
| `agentId` | `string` | Populated after enrollment |
| `source.channel` | `string` | Event log channel or syslog facility |
| `source.path` | `string` | File path for file-based sources |
| `host` | `object` | Endpoint identity (auto-populated by pipeline) |
| `event.type` | `string` | Event type within category |
| `event.action` | `string` | Specific action |
| `event.severity` | `integer` \| `string` | Severity level |
| `user` | `object` | User context |
| `process` | `object` | Process context |
| `network` | `object` | Network context |
| `file` | `object` | File context |
| `metadata` | `object` | CUSA-internal metadata |

## Sub-Object Schemas

### User

```js
{
  id,           // SID or UID
  name,         // username
  domain,       // domain or group
  type          // "User" | "System" | "Service"
}
```

### Process

```js
{
  pid,
  ppid,
  name,
  executable,   // full path
  commandLine,
  user
}
```

### Network

```js
{
  direction,    // "ingress" | "egress"
  protocol,     // "tcp" | "udp" | "icmp"
  source: { ip, port },
  destination: { ip, port }
}
```

### File

```js
{
  path,
  name,
  extension,
  size,
  hash: { sha256 },
  permissions
}
```

## State Objects (Not Events)

Inventory, FIM, and compliance results use separate schemas. They flow through the **state queue**, not the event queue.

### Inventory State Item

```js
{
  id,           // stable item identifier
  index,        // e.g. "wazuh-states-inventory-packages"
  operation,    // "create" | "update" | "delete"
  timestamp,
  data          // index-specific payload
}
```

### FIM State Item

```js
{
  id,
  index: "wazuh-states-fim",
  operation,
  timestamp,
  data: {
    path,
    mode,         // "file" | "directory"
    perm,
    uid, gid,
    md5, sha256,
    inode,
    mtime
  }
}
```

### Compliance Check Result

```js
{
  checkId,
  policyId,
  status,       // "passed" | "failed" | "not_applicable"
  severity,
  evidence,
  timestamp
}
```

## Wazuh Translation Mapping

The Wazuh serializer maps CUSA events to wire format based on protocol version.

### Legacy protocol (`v4/`)

| CUSA field | Wazuh wire |
|------------|-----------|
| `source.collector` + `source.channel` | Queue type + location |
| `raw` (string) | Message body |
| Windows events | Queue `f`, location = channel name |
| File logs | Queue `1`, location = file path |
| Sysmon | Queue `f`, location = `Microsoft-Windows-Sysmon/Operational` |

**Example translation:**

```js
// CUSA event
{
  source: { platform: "windows", collector: "event-channel", channel: "Security" },
  raw: '{"EventID":4625,...}'
}

// Wazuh plaintext (before encryption)
"f:Security:{\"EventID\":4625,...}"
```

### HTTPS protocol (`v5/`)

| CUSA field | Wazuh wire |
|------------|-----------|
| `host` + `agentId` | `agent` metadata line |
| `source.collector` | `collector` in sub-header |
| Module name | `module` in sub-header (derived from collector) |
| `raw`, `event.*` | `event` payload line |

**Example translation:**

```js
// Line 1: agent metadata (from enrollment identity + host)
// Line 2: {"module":"logcollector","collector":"windows-security"}
// Line 3: {"event":{"created":"...","original":"..."}}
```

### Fields NEVER sent to Wazuh wire

- `metadata` (entire object)
- `eventId` (internal dedup only)
- `collectedAt` (unless mapped to `event.created`)

## Validation Rules

1. `eventId` must be UUID v4
2. `timestamp` and `collectedAt` must be valid ISO 8601
3. `source.platform` must be `windows` or `linux`
4. `raw` must not be empty
5. `metadata` must not contain secrets (enforced by pipeline sanitizer)
6. Maximum `raw` size: 65535 bytes (configurable, matches Wazuh OS_MAXSTR constraint)

## Collector Output Contract

Collectors emit **partial events**. The pipeline enriches them:

```js
// Collector emits:
{
  source: { platform: "windows", collector: "sysmon", channel: "Microsoft-Windows-Sysmon/Operational" },
  event: { category: "process", action: "process-created" },
  process: { pid: 1234, name: "cmd.exe" },
  raw: "<xml>...</xml>"
}

// Pipeline adds:
{
  eventId: "uuid",
  agentId: "003",
  timestamp: "2025-10-05T...",
  collectedAt: "2025-10-05T...",
  host: { hostname: "...", os: "Windows", ... }
}
```

## Schema Versioning

The JSON Schema includes `$id` and `version` field for forward compatibility:

```js
{
  "$schema": "https://cybersio.local/cusa/event/v1",
  "version": 1
}
```

Schema changes increment version. Pipeline validates against configured version.
